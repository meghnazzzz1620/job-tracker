# Job Tracker – Full Stack Web Application

A production-ready job application tracking platform built using React, Spring Boot, and MySQL.

## 🚀 Live Demo
- Frontend: https://job-tracker-frontend-o78mw7x45-meghnas-projects-6c54da68.vercel.app
- Backend API: https://job-tracker-production-fe66.up.railway.app

## ✨ Features
- User authentication (login & signup)
- Add, update, and delete job applications
- Job status tracking (Applied, Interview, Offer, Rejected)
- Analytics dashboard with pie chart visualization
- Dark mode & modern glassmorphism UI
- Responsive and production-ready design

## 🛠 Tech Stack
### Frontend
- React
- Vite
- Recharts
- Axios

### Backend
- Spring Boot (Java)
- RESTful APIs
- Spring Security (CORS configured)

### Database
- MySQL (Railway managed service)

## ☁ Deployment
- Frontend deployed on **Vercel**
- Backend deployed on **Railway**
- Database hosted on **Railway MySQL**
- Environment-based configuration for dev & production

## 🧱 Architecture
- Frontend and backend are decoupled
- Frontend communicates with backend via REST APIs
- Backend handles business logic and database access
- Secure CORS configuration for production domains

## 📈 Scalability
- Stateless backend allows horizontal scaling
- Database can scale independently
- Easy to add JWT authentication and caching (Redis)
